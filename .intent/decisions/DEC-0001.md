The unified desktop is built by expanding `apps/desktop` in the existing `sixbyfive-tcg-admin` pnpm monorepo. No new repository is created.

## Rationale

- `packages/api-client` and `packages/types` are already there; new packages (kora-client) slot in naturally
- Auto-update pipeline, CI workflows, and electron-builder config are already wired — they carry forward
- Vision Lab's standalone repo (`H:\SBF-Vision-Lab`) has no shared packages to preserve; its code is copied in, not linked
- Kora API (`H:\care-platform-api`) is a backend — its repo stays separate and is never touched by this work

## Trade-offs accepted

- The monorepo's `admin-mobile` app (Expo) shares `node_modules` infrastructure; we must not break its workspace constraints when adding new packages or upgrading Electron
- The existing `apps/desktop` app name (`@tcg-admin/desktop`) will be renamed to something neutral (e.g. `@sixbyfive/desktop`) to reflect the expanded scope
