The combined app will target Electron 39.x (Vision Lab's current version) rather than 33.x (TCG Admin's current pin).

## Rationale

- Vision Lab's native modules (`sharp`, `ssh2`, `tesseract.js`) must be compiled against the host Electron version. They already build successfully against 39.
- Rebuilding them against 33 is possible but adds effort for zero benefit.
- Electron 39 includes security and performance improvements over 33.

## Trade-offs accepted

- Electron 33 → 39 skips 6 major versions. The TCG admin UI (pure React/Tailwind renderer) is unlikely to be affected, but the upgrade must be tested.
- `electron-updater` behaviour and NSIS installer config should be re-validated after the bump.
- The `admin-mobile` Expo app is unaffected — it does not depend on Electron.

## Implementation

1. Update `apps/desktop/package.json`: `"electron": "^39.0.0"`
2. Run `pnpm install` — electron-builder will download the new binary
3. Smoke-test all existing TCG admin pages before merging any Vision Lab code
4. Rebuild native deps: `electron-rebuild` (or via `electron-builder install-app-deps`)
